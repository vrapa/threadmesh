### Added

- Initial connector contracts and normalized domain model.
- Test and static-analysis configuration.
- Public project documentation.
- Incremental read-only IMAP connector with MIME normalization and UIDVALIDITY checks.
- Encrypted SQLite persistence, HTTP API, and local MCP server.
- Structured assessments, mail alerts, invoice fields, and local reply drafts.
- Explicitly confirmed IMAP Drafts append without any send capability.
- English and Czech usage, automation, API, MCP, and agent documentation.
- MCP safety annotations for read-only, destructive, idempotent, and external operations.
- Hardened local Docker image and Compose deployment with shared persistent SQLite storage.
- English and Czech Docker setup, update, security, and backup instructions.
- Public alpha presentation with architecture diagram, usage scenario, limitations, commercial support, expanded security policy, and Docker CI.
